# SunPlayer 1.3.0.1.1

SunPlayer 1.3.0.1 is the durable local-library foundation release and Android 16/API 36 compatibility release.

## Included

- Room-backed track library with schema migrations.
- Persistent Favorites preserved across successful rescans.
- Failed MediaStore scans no longer clear the existing library.
- Media3 background playback through `MediaSessionService`.
- Queue add-next, add-to-end, remove, reorder, and clear-upcoming actions.
- Normal playlists with create, rename, delete, ordered membership, and
  playlist playback.
- Playlist persistence and missing-track membership protection.
- Focused persistence and scanner regression tests.
- Java 17 CI build and release artifact workflow.
- Android 16 (API 36) compile/target configuration.
- Edge-to-edge support for Android 15/16 behavior.
- Release APK and Android App Bundle (AAB) artifacts.

## Verification

The release workflow uses Temurin Java 17 and verifies unit tests, release/debug
builds, Android instrumentation tests, and Android 16 emulator compatibility.

## Platform compatibility

Google Play requires new apps and updates to target Android 16 (API 36) from
August 31, 2026. This release targets API 36 and uses Android 16 instrumentation
coverage. The CI workflow also reports native `.so` libraries present in the
release APK for 16 KB page-size follow-up.

## Signing note

Release builds are unsigned unless protected signing secrets are configured.
Tagged releases fail before packaging without those secrets, so no debug-signed
APK is published as a production release.

## Deferred

Unavailable playlist item UI, library navigation tabs, playback history,
incremental scanning, artwork, metadata editing, and advanced audio features
remain outside this release.
