# SunPlayer 1.4.0

SunPlayer 1.4.0 is the library-navigation, ratings and self-update release.

## Included

- Library navigation tabs: Tracks, Albums, Artists, Favorites, and Playlists.
- Album and artist views with drill-down filtering and clear-filter controls.
- Playlists tab: browse playlists, open one to add/remove/reorder tracks, play or
  shuffle it; the old floating "Your playlists" button is gone.
- Per-track 0–5 star ratings, editable from the library list and from the
  now-playing sheet, persisted in the Room database.
- In-app update check against GitHub Releases: detects a newer signed release,
  shows the release notes, and downloads it only on confirmation before handing
  it to Android's package installer.
- Automatic releases: merging a version bump with its changelog to `main` now
  creates the matching tag and publishes the signed APK/AAB (the `release`
  environment approval gate still applies).

## Privacy note

This release adds the `INTERNET` permission for the update check only. The app
still sends no account, library, playlist or listening data anywhere; the update
check is a plain HTTPS request to GitHub's public Releases API. The privacy
policy (`docs/privacy.html`) was updated to describe it.

## Verification

The release workflow runs the gitleaks secret scan, unit tests, debug and signed
release builds, the SHA-256 checksum job and the Android emulator instrumentation
smoke test before publishing.

## Upgrade

No database migration is required beyond the existing rating column migration;
installed 1.3.x builds keep their library, playlists and favorites.
