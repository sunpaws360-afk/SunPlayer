SunPlayer Privacy Policy

Last updated: 28 October 2026
Package: com.rebecca.sunplayer

The short version

SunPlayer is an offline-first music player with no account, no ads, no analytics, and no tracking of any kind. The only network access is an optional update check against GitHub's public release feed, which sends no personal data. Your music, playlists and listening habits never leave your device.

Data SunPlayer processes

  • Audio files on your device. On Android 13+ SunPlayer requests READ_MEDIA_AUDIO (on older versions, storage read up to API 32) so it can list and play the music already stored on your device. It does not read documents, photos, messages, or call logs.
  • Library index, playlists, favourites, ratings, play counts and history. These are stored in a local database inside the app's private storage on your device. They never leave the device.

What leaves your device

One thing only: the in-app update check.

  • On installed release builds, SunPlayer may send a standard HTTPS GET request to GitHub's public Releases API (api.github.com/repos/sunpaws360-afk/SunPlayer/releases/latest) to learn the latest published version number.
  • That request carries only what any HTTPS request carries — your IP address (visible to GitHub as the server) and a generic User-Agent string. No library contents, playlists, ratings, listening history, account, or device identifiers are sent.
  • No update is downloaded or installed unless you tap Download and then confirm in Android's own package installer. The APK is fetched over HTTPS from GitHub, stored in the app's private cache, and removed after installation.
  • There are no advertising or analytics SDKs, no telemetry, and no other network calls. Debug builds never check for updates.

Cloud backup

If you have Android's built-in backup enabled, the OS may include the app's small local database (playlists/favourites) in your device backup according to Google's Android backup terms. You can disable this in system settings. Cached data and temporary files are excluded from backup.

Data deletion

  • Uninstalling SunPlayer removes its database and all app data immediately.
  • Your music files are never modified or deleted by the app.
  • Android “Clear app data” (system settings) wipes everything the app has ever created.

Children's privacy

SunPlayer collects no personal information from anyone, including children. Everything is processed locally; the only network request is the version check described above, which transmits no personal information.

Changes to this policy

If future versions add other network features (for example optional metadata lookup or AI), they will be opt-in with an explicit toggle and this policy will be updated before such a release. Core playback and library management remain fully functional without any network access.
